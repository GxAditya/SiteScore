# SiteScore - SEO Page Auditor
AI search is changing how pages get found. Build an auditor that checks whether AI search and fetch tools can actually read and understand a page, and how that ties to SEO and ranking. Use TinyFish Search to see how a page shows up, Fetch to see what an AI tool extracts from it, then report what's missing and how to fix it.


## Requirements
1. Takes a URL (and optionally a target search query)
2. Uses TinyFish Search and Fetch
3. Report covers what AI tools can and can't read, visibility gaps, and concrete fixes
4. Search and Fetch both contribute meaningfully
5. Audits live pages rather than saved copies
6. Findings are specific and actionable, not generic SEO tips
7. Works for any URL
8. Connects how readable a page is to AI tools with how visible it is in search

## What we’re looking for
An audit a site owner would act on the same day.

# Stack Requirements
- Must use Tinyfish api for search / fetch funtionalities
- Must be able to deploy working app to free versions of either vercel/netlify/cloudflare
